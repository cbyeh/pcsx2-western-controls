## v1.1.0

### KH2
- **Tutorial prompts fixed:** "Jump with ○" now shows a red ○. The new `Swap X and O button prompts` patch swaps the ○/× entries (symbol and colour) in KH2's button sprite table. The grey-symbol texture swap is no longer needed and has been removed.

### KH1
- **Right Stick Camera no longer interferes with Gummi mode:** the stick only drives the camera in the field. In the Gummi Garage, the world map and Gummi flight it does nothing, so the Garage (L2 = layer down, R2 = Inspect Mode) and flight (R2 = score display) work normally.
- **New `60 FPS` patch:** PeterDelta's database patch, ported. Game speed is compensated, and it drops to 30 FPS for FMVs and scripted scenes.
- **New optional `HP/MP gauge fix`:** ported from the database.
- **World map prompt:** the button bar now reads "× Depart" (new texture).

### Docs
- Added a section explaining digital pad mode.

Tested in PCSX2 v2.9.129. See the README for what was checked.
