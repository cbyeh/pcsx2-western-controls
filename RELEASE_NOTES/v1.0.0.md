First release. Western button layout (× confirm / ○ cancel) for three Japanese PS2 releases, with prompt swaps and extras.

**Download `pcsx2-western-controls-v1.0.0.zip`** and copy its `PCSX2/` folder over your PCSX2 user folder (usually `Documents\PCSX2`). The individual `.pnach` files are attached too if you only want the patches. Setup steps are in the [README](https://github.com/cbyeh/pcsx2-western-controls#install).

| Game | Serial / CRC | Included |
|---|---|---|
| Kingdom Hearts Final Mix (English patch) | SLPS-25198 / BD3FB233 | X/O swap, prompt textures, Right Stick Camera (+ inverted), Widescreen 16:9 |
| Kingdom Hearts II Final Mix+ (Crazycatz00) | SLPM-66675 / FAF99301 | X/O swap, prompt textures |
| Final Fantasy X International | SLPS-25088 / 658597E2 | X/O swap, prompt-swap patch |

Tested together with PCSX2's built-in widescreen / 60 FPS / blackbar patches; `tools/audit_pnach.py` reports no overlapping writes.

**Known issues:** KH2 in-field tutorial icons show ○ in ×'s blue tint. KH1's right-stick camera also presses L2/R2, which the Gummi Garage uses. Both are being worked on for the next release.
